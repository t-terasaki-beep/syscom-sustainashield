# 外壁塗装の見積が同じ面積でも変わる理由

**先に結論からお答えします。**
同じ面積でも見積が変わるのは、**面積単価だけで工事金額が決まらない**からです。
足場・洗浄・下地補修・部位・仕様・保証条件が建物ごとに違うため、金額も変わります。
「6,000円／㎡〜」はあくまで**概算の起点**で、確定価格ではありません。

## 見積が変わる6つの要素
| 要素 | なぜ変わるか |
|---|---|
| 足場 | 建物の高さ・形状・敷地条件で架設範囲が変わる |
| 洗浄 | 汚れ・旧塗膜・コケの状態で手間が変わる |
| 下地補修 | ひび割れ・シーリング・板金の傷みは先行補修が必要になる |
| 屋根／外壁 | 材種・面積・塗り分けで仕様が変わる |
| 部位 | 付帯部（軒天・破風・雨樋）ごとに材料と工程が変わる |
| 仕様・保証 | 遮熱のみか断熱を組み合わせるか、保証条件で変わる |

【写真差し替え】シーリングの打ち替え / 下地補修 / 塗布量の記録

## 「安い見積」を見抜くチェックポイント
- 数量（㎡・m）と単価が明記されているか
- 下地補修・シーリングが「一式」でまとめられていないか
- 塗料の**製品名と塗布量**が書かれているか
- 保証範囲・除外事項が明記されているか

## 当社の見積の出し方
当社は必ず**3案（安い案／推奨案／将来工事を減らす案）**を並べてお出しします。
現地診断で下地の状態を確認したうえで、数量と単価を明記します。
「通常の塗料より絶対に長持ち」といった根拠のない比較は行いません。
