# 海沿いの戸建てで先に見るべき場所

**先に結論からお答えします。**
海沿いの戸建てで最初に確認すべきは、外壁の色よりも**金属部**です。
具体的には **屋根板金・雨樋（金具）・シャッター・金属サイディングの端部や留め具**。
これらは飛来塩分の影響で発錆・腐食が進みやすく、放置すると塗装だけでは解決できない補修に広がります。

## 先に見るべき5か所
| 場所 | 見るポイント |
|---|---|
| 屋根板金（棟・谷・水切り） | 発錆、接合部の浮き、釘・ビスの錆 |
| 雨樋・雨樋金具 | 金具の腐食、勾配のくるい、割れ・詰まり |
| シャッター | スラット・レールの発錆、動作の重さ |
| 金属サイディング | 端部・留め具の錆、塗膜の劣化 |
| 外壁・シーリング | 塩分を含んだ風雨によるチョーキング、目地の劣化 |

【写真差し替え】板金接合部の発錆 / 雨樋金具の腐食 / シャッターレールの錆

## なぜ「金属部が先」なのか
外壁の塗り替えだけを先に行っても、金属部の腐食が進んでいれば、
数年後に別工事が必要になります。
沿岸では**遮熱・耐候・防錆・防汚を一体で**考えることで、
暑さ対策と建物保全を同時に設計できます。

## 当社の診断
- 金属部・留め具・板金接合部・雨樋金具・シャッターを**別項目で記録**する
- 発錆・腐食の程度を写真と合わせて残す
- 塗膜だけで原因が解決しない場合は、補修を先行させる

> ※塩害リスクは海からの距離だけでは決まりません。風向き・地形・飛来塩分・建物の向き・下地の状態を現地で確認します。
