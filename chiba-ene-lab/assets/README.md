# 千葉エネ研究会LP 画像スロット

このフォルダに以下のファイル名で画像を置くと、LPの背景・バンドに自動で反映されます。
**画像が無くても**、各所はグラデーションで成立するよう作ってあります（差し替えると一気に写真前提の見栄えになります）。

| ファイル名 | 使われる場所 | 推奨サイズ / 内容 |
|---|---|---|
| `hero.jpg`    | ファーストビュー背景 | 1600×1000 程度・横長。系統用蓄電池／太陽光＋千葉の風景など「エネルギー感」のある写真 |
| `land.jpg`    | 2大テーマ「土地活用」カード | 1200×900 程度。遊休地・造成地・用地のイメージ |
| `battery.jpg` | 2大テーマ「系統用蓄電池」カード | 1200×900 程度。蓄電池コンテナ・パワコン・連系設備など |
| `members.jpg` | 「守る・盛り上げる」バンド背景 | 1600×1000 程度。**加盟企業の集合写真**（今回いただいたもの） |

## 注意
- 集合写真など人物が写るものは、**写っている各社の公開同意**を確認のうえ掲載してください（事務局＝寺嵜の判断）。
- 著作権・肖像権に配慮し、自社／加盟企業が権利を持つ写真、または正規にライセンスした素材を使用してください。
- ファイルは JPG（または WebP/PNG）。ファイル名は上記のとおり（小文字）。
