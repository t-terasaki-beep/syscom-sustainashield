## LPの構成
ファーストビュー → なぜ塗り替えだけでは足りないのか → 千葉の海風と塩害（#coast）→
動画で見る 屋根・外壁診断と性能施工（#video）→ 遮熱ポリウレアという選択 →
6,000円／㎡〜の意味 → 3プラン（ベーシック保全／塩害・遮熱強化／冷暖まるごと）→
診断の見える化（金属部の発錆・腐食を含む）→ 窓・太陽光までつなぐ提案 →
施工品質 → 施工事例（同一アングルBefore/After）→ よくある質問（塩害を含む）→ 最終CTA

## 表現管理ルール（公開前チェック）
- [ ] 「通常の塗料より絶対に長持ち」「必ず電気代が下がる」等の断定を使っていない
- [ ] 「20年以上耐候」は製品・施工仕様上の性能説明として記載し、保証年数を約束していない
- [ ] メーカー掲載内容を「全ての戸建て屋根・外壁にそのまま適用できる」と広告していない
- [ ] 塩害について「海から何kmまで大丈夫」「塩害を完全に防ぐ」「全ての屋根に20年以上」等の一律表現を使っていない
- [ ] 防水・遮熱・断熱・省エネの数値は、出典・試験条件・対象製品が確認できるものだけを使用
- [ ] LP本文で句点「。」を使用していない（noteドラフトは通常の文体でよい）
