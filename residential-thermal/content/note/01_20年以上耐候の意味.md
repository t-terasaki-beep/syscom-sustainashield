# 「20年以上耐候」は何を意味するのか

**先に結論からお答えします。**
「20年以上耐候」は、メーカーが**試験条件のもとで示す製品・施工仕様上の性能説明**であって、
どの戸建て屋根・外壁でも必ず20年もつことを約束する数字ではありません。
実際の耐用は、屋根材・外壁材・既存塗膜・下地の状態・気象・使用条件で変わります。
お客様への**保証年数**は、対象製品と施工仕様が確定し、メーカー保証書・施工保証書が発行された時点で決まります。

## 1. 混同されやすい3つの「年数」
| 用語 | 何を指すか | 誰が保証するか |
|---|---|---|
| 耐候年数（製品性能） | 試験条件下での塗膜の耐久性の目安 | メーカーの試験データ |
| 施工仕様上の性能 | 規定の下地処理・塗布量で施工した場合の性能 | 施工仕様書 |
| 保証年数 | 実際の建物・施工に対して約束する年数 | メーカー保証書・施工保証書 |

「20年以上耐候」は左の2つの話です。右の「保証年数」はまた別で、**現地の状態と施工内容が確定して初めて決まります。**

- 掲載根拠：（メーカー提供ページのURL）

> 数値を紹介するときは、必ず「出典・試験条件・対象製品」をセットで示します。条件の書かれていない数字は使いません。

## 3. 当社の診断・施工判断
1. 屋根材・外壁材・既存塗膜・劣化状態を現地で確認し、メーカー施工仕様書との**適合可否**を判定する
2. 適合しない下地には、そのまま高耐候仕様を載せない（先行補修や別工法を提案する）
3. 施工前後の**温度・含水率・写真・塗布量**を記録し、性能説明と実際の施工をひも付ける

【写真差し替え】診断チェックの様子 / 塗布量の記録 / 施工仕様書との照合

## 4. よくある誤解
- 「高耐候の塗料を塗れば必ず20年もつ」→ 下地と施工次第で変わります
- 「耐候年数＝保証年数」→ 別物です。保証は保証書で確定します
