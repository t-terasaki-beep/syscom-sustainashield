「こっちは暑いけど」

設定温度は一つなのに、感想は二つ。試しに席を替えてみたら、今度は意見まで入れ替わりました。

リモコンの表示は、ずっと同じです。

サステナシールドの寺嵜です。

家の暑さを話すとき、人による感じ方の違いに加えて、過ごしている場所の違いも見てみたいと思います。

家の中にも、条件の違う場所がある

窓に近い席、屋根に近い二階、風の届きにくい場所。

日差しや熱の出入り、空調の届き方によって、同じ部屋でも感じ方が変わることがあります。

「誰が暑がりか」で話を終える前に、どこで何時に気になるかを確かめてみます。

窓や屋根・天井の対策を検討するときも、遮熱と断熱を同じものとして扱わず、建物の状態と季節を見て選びます。工法を一つ決めてから、すべての部屋に当てはめる必要はありません。

つくる電気と、必要な電気

太陽光は電気をつくる設備です。建物の熱の出入りへの対策は、冷暖房に必要な負荷を見直す方向です。

どちらも検討できますが、効果の数字は単純に足せません。電気を使う量や時間が変われば、自家消費や売電の量も変わるからです。

自家消費率が高いことだけを目標にせず、買う電気、費用、過ごしやすさを一緒に見たいところです。

一部屋から考えてもいい

家全体を一度に変えるのが難しければ、長く過ごす部屋を入口にできます。

「午後にここで仕事をする」「夜はこの部屋で眠る」と分かれば、優先順位を相談しやすくなります。

工事前後を比べるときは、気温や生活時間などの違いも記録します。電気代だけが変化の説明になるとは限りません。
