サーモ画像の赤いところは、怒っているわけではない｜建物の暑さを読む

サーモ画像を見ると、赤い場所に目が向きます。なんだか、そこだけ強く主張しているようです。

ただ、色は温度を見やすく表すためのもの。赤いからすぐに工事、というわけではありません。

サステナシールドの寺嵜です。

今回は実際の施工事例ではなく、建物の暑さを調べるときに、画像とどう付き合うかのお話です。

きれいな画像にも、撮った事情がある

サーモグラフィでは、表面の材質や放射率、周囲からの反射などが測定に影響します。表示する温度範囲が違えば、画像の色の見え方も変わります。

とくに反射しやすい面は、表面そのものと周囲の影響を分けて考える必要があります。FLIRの放射率・反射の説明
https://www.flir.com/ja-jp/discover/professional-tools/how-does-emissivity-affect-thermal-imaging/

画像を並べるなら、撮影した時間、天気、場所、設定も一緒に残す。数字の横に事情があると、比較の意味が変わります。

屋根の温度と、人の暑さをつなぐ

屋根の表面が熱いことは、調べる手がかりです。ただ、それだけで室温や人の感じ方を説明しきれるとは限りません。

どこで作業するか、何時に困るか、空調はどう動いているか。建物の中の時間割も重ねて見ていきます。

例えば架空の倉庫で、「入口は平気だけれど、奥の棚で午後に暑い」と聞けたら、確認したい場所が具体的になります。画像が現場の声の代わりになるのではなく、両方があることで調べ方が育ちます。

最初に残すのは、温度より一言でもいい

専門のカメラが手元になくても、「午後、この場所で困る」というメモは役立ちます。安全な場所からの普通の写真も、位置関係を伝える材料になります。撮影のために屋根へ上る必要はありません。

赤いところを探すことから、人が困っている時間を探すことへ。

あなたの建物で、最初に話を聞いてみたい場所はどこでしょうか。

整理しきれないところがあれば、今分かっていることから一緒に考えます。
