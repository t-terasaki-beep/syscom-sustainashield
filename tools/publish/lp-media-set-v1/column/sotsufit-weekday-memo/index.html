わが家の電気にも、平日と休日がある｜卒FITの一枚メモ

架空の家族の会話です。

「うちは昼間、誰もいないよね」

「火曜日は在宅勤務だよ」

「土曜日は？」

電気の使い方を話していたら、家族の予定表の確認になりました。屋根の太陽光より先に、お互いの一週間に発見がありました。

サステナシールドの寺嵜です。

卒FIT後の電気の使い方を考えるとき、平均的な一日だけでは、ご家庭の暮らしを描ききれないことがあります。

紙を三つに分けてみる

朝、昼、夜。それぞれに、よく使う設備を書きます。

朝の台所、昼の空調、夜のお風呂。次に、平日と休日で違うところへ丸を付けます。

消費電力を暗記していなくても構いません。これは計算を完成させる紙ではなく、次に何を調べるかを見つける紙です。

「昼は不在」でも、冷蔵庫などは動いています。逆に在宅していても、太陽光の発電を使い切るとは限りません。在宅時間は手がかりであって、実際の余剰量の代わりにはなりません。

分かる数字だけ、後から足す

電力会社や機器のアプリに時間帯別データがあれば、生活のメモと見比べます。発電、売電、買電は違う項目なので、名前も一緒に残します。

数字が取れなければ「不明」と書きます。不明をゼロにしないことも、役立つ記録です。

卒FIT後には売電を続けることや、自宅で使うことなどの選択肢があります。資源エネルギー庁の案内
https://www.enecho.meti.go.jp/category/saving_and_new/saiene/solar-2019after/

どの選択肢を詳しく調べたいかは、この紙と現在の契約条件から考えられます。

暮らしを、設備の都合だけで変えない

電気を使う時間を動かせる家事もあれば、動かしにくい仕事や家族の予定もあります。

無理なく続けられることと、変えたくないことを分けておけば、提案を受けるときも希望を伝えやすくなります。

この一週間で、わが家らしい電気の使い方が表れるのは何曜日でしょうか。

答えを探す紙は、見積を依頼するためだけでなく、家族を少し知るためにも使えそうです。
