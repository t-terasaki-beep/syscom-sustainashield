太陽光と屋根の修繕、同じ日に相談してみたら｜設備投資の順番

架空の打合せで、机の上に二つの見積が並びました。

一つは太陽光。もう一つは屋根の修繕。

「どちらを先にしましょう」

しばらく見比べてから、担当者が言いました。「まず、この二人に同じ日に来てもらえますか」

見積同士は、まだ名刺交換をしていなかったのです。

サステナシールドの寺嵜です。

別々に進めている設備の相談も、同じ建物で行うなら、工程や将来の維持管理が関係することがあります。

順番は、標語だけでは決まらない

使う電気を減らす、発電する、蓄える。全体を見渡すうえで役立つ考え方です。

ただし、すべての現場で同じ順番が最適とは限りません。屋根の状態、設備の更新時期、必要な機能、予算、工事できる時期によって判断は変わります。

先に必要な修繕があるのか。太陽光と同時に検討できるのか。既存設備を続けて使えるのか。

まずは、それぞれの見積が何を前提にしているかを並べます。

発電の話に、点検の予定も入れる

太陽光を設置したあとの屋根点検や修繕は、どう行う計画でしょうか。

設備の配置、作業する場所、必要に応じた取り外しなどを、設計の段階で確認しておくと、将来の比較が具体的になります。

取り外しが必要か、何回あるか、費用はいくらかは構成と維持管理計画次第です。一律の回数や金額は置きません。

暑さ対策もあわせて検討するなら、電気の使用量だけでなく、作業環境として何を改善したいかを確認します。省エネで使う量が変われば、太陽光の自家消費の見立ても見直します。

次の打合せで、席を一つ増やす

すべてを一度に工事する必要はありません。今することと、後でできることを分けるために、一緒に相談する方法もあります。

あなたの会社で別々に進んでいる計画のうち、一度同じ机に並べてみたいものはありますか。

順番の答えは、二つの担当が前提を共有したところから見えてくるかもしれません。

整理しきれないところがあれば、今分かっていることから一緒に考えます。
