サステナシールドの寺嵜です。

昼にお湯をつくることと、昼にお湯を使うことは別です。タンクに用意したお湯を、夜の暮らしへつなぐ。ここが分かると、機器の考え方が少し身近になります。

家族が留守でも、お湯の支度はできる

おひさまエコキュートは、昼間の沸き上げを中心に使う給湯機です。太陽光と組み合わせて、その時間の発電を活かすことを考えます。

昼に人がいるかだけで適否は決まりません。ほかの設備の電気使用や発電の状況、お湯の必要量を確認します。パナソニックの製品説明

日射が不足する日には、購入した電力を使う場合もあります。太陽光があるから、給湯費がなくなるというわけではありません。

今の給湯器にも、できることがあるかもしれない

通常型のエコキュートにも、機種によって昼間の沸き上げを活用する機能があります。

それを使うことと、おひさまエコキュートへ交換することは、別の選択肢です。現在の型番と説明書を確認すれば、使い方の見直しから考えられる場合もあります。

契約している電気料金や対応条件も合わせて確認します。

お湯の使い方は、家庭ごとの時間割

朝にシャワーを使う、入浴する時間が家族で離れる、休日は使用量が変わる。

ご家庭の予定を聞くのは、暮らしを機器に合わせるためではなく、必要なお湯をどう用意するか考えるためです。

交換を検討するなら、設置場所や工事の条件も確認します。
