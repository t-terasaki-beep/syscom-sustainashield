太陽光・蓄電池2026.09.28

卒FITの案内が届いた日、屋根はいつも通りだった

「卒FITのお知らせ」が届いた場面を想像してみてください。

卒業と聞くと、何かが終わるような気がします。ところが屋根を見上げても、太陽光パネルはいつもの場所です。もちろん、卒業式の予定もありません。

サステナシールドの寺嵜です。

知らない制度の言葉が届くと、急いで何か決めなければと思うことがあります。最初は、何が変わり、何が続くのかを分けてみましょう。

区切りが来るのは、買取の期間

卒FITは、固定価格で買い取る期間が満了することを指す言葉です。

期間が終わること自体で、太陽光設備が使えなくなるわけではありません。設備の状態を確認しながら、その後の電気の扱い方を考えます。

売電を続ける場合は、契約先や条件を確認します。資源エネルギー庁「どうする？ソーラー」
https://www.enecho.meti.go.jp/category/saving_and_new/saiene/solar-2019after/

売電を続ける、自宅で使う、蓄電池などで使う時間を移す。どれか一つだけを選ばなければならないとは限りません。

案内を読んだ人と、機器を決める人が違ってもいい

家族の中には、契約の書類を読む人、家計を考える人、機器の操作に詳しい人がいるかもしれません。

一人ですべて理解しようとせず、満了日、現在の契約先、今後の条件を一緒に確認します。契約番号などの個人情報は、公開のコメント欄へ載せないでください。

次に、最近の発電や売電、買電の記録を手元に置く。分からない項目は空欄のままで、何を問い合わせるかを決められます。

屋根の設備と、これからの暮らし

設置したころと今とで、家族の人数や在宅時間が変わっているかもしれません。

今の暮らしで使いやすい方法を考えれば、以前と同じ選び方でなくても自然です。設備を追加せず契約の確認から進める選択もあります。

案内を開いたら、最初に何を知ると安心できそうでしょうか。

その一つが分かるだけでも、「何となく心配」から、次に聞きたいことがある状態へ進めると思います。

整理しきれないところがあれば、今分かっていることから一緒に考えます。
