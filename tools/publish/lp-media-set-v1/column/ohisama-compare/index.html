晴れた日だけの家計簿にしない｜おひさまエコキュートの比べ方

架空の家族の会話です。

「今日はよく発電しているね」

「じゃあ、お湯も安く沸かせそうだね」

そこへ天気予報が「明日は雨」と言いました。家計の相談に、空から一人参加してきたようです。

サステナシールドの寺嵜です。

太陽光をお湯づくりに活かすのは、分かりやすい考え方です。その相性を確かめるなら、よく晴れた日と、そうでない日の両方を見てみたいと思います。

「発電した量」と「使える余り」は違う

昼間の電気は、冷蔵庫や空調なども使っています。給湯へ回せる量を考えるときは、発電の合計だけでなく、ほかの設備で使った後の状況を確認します。

さらに、その電気を給湯に使えば、売電に回す量は変わります。

自宅でつくった電気だからといって、比較のうえで価値をゼロに置く必要はありません。

雨の日のお湯にも、費用がある

おひさまエコキュートは昼間の沸き上げを中心に使う機器です。メーカーは、太陽光が発電しない天候の日には契約電力で沸き上げることも説明しています。パナソニックの説明
https://sumai.panasonic.jp/hp/ohisama/

したがって、現在の給湯費、買う電気の条件、売る電気の条件、お湯の使用量をそろえて比べます。機器代と工事費、将来の維持費も別に確認します。

家族の予定も、計算の一部

朝にシャワーを使う人、夜にゆっくり入る人。お湯の使い方は家庭によって違います。

数字をきれいにするために暮らしを無理に変えるより、続けられる使い方で比べるほうが、自分の家の判断に近づきます。

手元にある発電・売電・買電の記録と、最近のお風呂の使い方を並べてみてください。機器を買う結論まで出さず、「この時間はどうなっているんだろう」が一つ見つかれば十分です。

ご家庭の家計簿に、まだ登場していない天気や時間帯はありませんか。

整理しきれないところがあれば、今分かっていることから一緒に考えます。
