省エネ・電気代2026.09.28

電気代の会議に、現場の「暑い」も一席つくる｜電力の見える化

架空の工場の打合せです。

社長は「電気代を下げたい」と言います。現場は「もう少し涼しくしたい」。総務は「工事はいつできますか」。

三人とも会社をよくしたいのに、会議の議題が三つあります。エアコンのリモコンだけが、全員から見つめられています。

サステナシールドの寺嵜です。

こういう場面を考えると、省エネの入口に必要なのは、誰かの我慢を決めることより、お互いが見ている状況を持ち寄ることだと感じます。

請求書には、現場の時間割が書いていない

月の使用量は大切な情報です。ただ、それだけでは、どの設備がどの時間に動いていたかまでは分かりません。

回路別の計測と、営業時間や生産設備の運転記録を重ねると、調べる場所を絞りやすくなります。

夜間の電力も、すべてが無駄とは限りません。冷蔵や保安のように、止められない仕事があります。

数字にも、担当する仕事がある

電流のA、電力のkW、使った量を表すkWhは、同じ数字ではありません。

使用量を減らしたいのか、負荷が集中する時間を見たいのか、設備が止まる前後を調べたいのか。目的によって必要な記録が変わります。

一定間隔で保存した最大値では、短時間の変化を拾えない場合もあります。

慧通信技術工業のSmart Meter ASPは、記録に加え通知や異常時刻前後の解析を案内しています。追加回路や記録間隔、費用は構成ごとに確認が必要です。メーカーのサービス説明
https://www.ieee802.co.jp/smartmeter/smartmeter_industry.php

次の会議へ持っていくもの

最初から大きな計測システムを決めなくても構いません。

「暑いのは何時ごろか」「止められない設備は何か」「変更できそうな運転時間はあるか」。それぞれの担当が一つずつ持ち寄るだけでも、話は具体的になります。

工事後の効果を比べる際も、気温や生産量などの条件を合わせます。

あなたの職場の電気代の話に、まだ席が用意されていない声はあるでしょうか。

その声を聞くことが、次に測る場所を教えてくれるかもしれません。

整理しきれないところがあれば、今分かっていることから一緒に考えます。
