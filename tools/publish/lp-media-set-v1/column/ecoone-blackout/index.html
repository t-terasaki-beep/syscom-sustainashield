停電の備えを話したら、家族の大事なものが違っていた｜エコワンソーラー

ある家族の、架空の会話です。

「停電したら、何を使いたい？」

「冷蔵庫」「お風呂」「スマホ」

それぞれの答えが出たあとで、「懐中電灯、どこだっけ」と声が上がりました。電源の会議は、まず引き出しを探すところから始まりそうです。

サステナシールドの寺嵜です。

冷蔵庫には明日の食事、お風呂には一日を終える時間、スマホには離れた家族との連絡があります。答えが違うのは、心配していることが違うからかもしれません。

電源の容量より先に、暮らしの名前を書く

停電への備えを考えるなら、使いたい設備を紙に並べてみる。その横に「いつ」「どれくらい」を足すと、ご家庭の優先順位が見えてきます。

全部を同時に使いたいのか、順番に使えればよいのかでも、必要な構成は変わります。希望が多くても、まずは削らず書いてみてください。

給湯の継続には、対応する電源だけでなく給水や機種に応じたガス等も必要です。タンクのお湯を使うことと、新しく沸かすことは分けて確認します。

日射、充電残量、使用する機器によって使える時間も変わります。「これなら何日でも」と、容量だけで約束はできません。

買い物の前にできる、小さな備え

今ある給湯器の型番と説明書を確認する。家族が使いたい設備を三つ挙げる。それも備えの一歩です。

機器の置き場所は浸水の可能性や点検のしやすさまで検討します。屋外用という表示だけで水没に耐えるとは判断しません。

すぐに設備を増やすかどうかは、そのあとで決められます。

ご家庭で最初に挙がるのは、どんなものでしょう。意外な答えの向こうに、家族の大切な時間があるかもしれません。
