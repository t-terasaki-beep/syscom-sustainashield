太陽光・蓄電池2026.09.28

蓄電池に頼みたい仕事、家族で同じでしょうか｜卒FIT後の選び方

架空の家族会議です。

「蓄電池があれば、電気代が気にならなくなるかな」

「私は停電のときが心配」

同じカタログを見ていたのに、頼みたい仕事が違いました。蓄電池も、採用面接で二つの職務を渡された気分かもしれません。

サステナシールドの寺嵜です。

節約したい気持ちと、非常時に備えたい気持ち。どちらも大切ですが、判断する材料は少し違います。

普段の仕事と、もしもの仕事

普段の電気の使い方を見直すなら、昼間に余る電気や夜間の使用量、買電と売電の条件を確認します。充放電には損失もあり、導入費用と維持費を含めて比較します。

停電対策を考えるなら、動かしたい設備と時間、必要な出力、接続できる回路を確認します。

容量が同じでも、対応できる使い方が同じとは限りません。

希望が違うなら、比較の欄を分ける

見積を見ながら「得かどうか」だけで話すと、停電への不安が置き去りになる場合があります。

逆に安心という言葉だけでは、家計を預かる人の疑問が残ります。

普段の費用と、備えとしてできることを別々に並べてから、一緒に考えるほうが話しやすくなります。

昼の電気を給湯へ使う方法や、既存設備を続けて使う方法も含めて検討できます。すべてを同時に導入する必要はありません。卒FIT後の選択肢については、資源エネルギー庁も自家消費や売電を案内しています。公的な案内

結論の前に、理由を一つ

家族それぞれが「何のために検討しているか」を一行書く。数字を集めるのは、そのあとでも大丈夫です。

すぐ導入する、別の対策を先にする、今は見送る。条件を比べて選べたなら、いずれも考えた結果です。
